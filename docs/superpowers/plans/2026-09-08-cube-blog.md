# Cube Blog Implementation Plan

> **For agentic workers:** Execute independent components in parallel, then integrate and verify in the existing Flask app. User authorized implementation of the combined design.

**Goal:** Deliver a working local cube blog prototype matching the approved mockup.

**Architecture:** Flask renders the archive and reading pages. A page-specific controller synchronizes a Three.js cube, native focusable pins, and a stable preview. Sample content stays local to debug/test contexts.

**Tech Stack:** Existing Flask/Jinja, local Inter fonts, vanilla JavaScript, vendored Three.js, Node test runner, pytest.

**Spec:** `docs/superpowers/specs/2026-09-08-cube-blog-design.md`

## Global constraints

- Preserve existing homepage behavior and design tokens.
- Blog before Expertise; `/blog/` and `/blog/<slug>/`.
- No production publication, external messages, or new services.
- Sample titles and writing are identified as illustrative.
- Touch, keyboard, reduced motion, and a no-WebGL article list remain usable.
